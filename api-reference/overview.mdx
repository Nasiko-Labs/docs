The control plane exposes one HTTP API — the same one the CLI, web UI, and admin tools use. Everything from deploying an agent to querying a trace is a REST or JSON-RPC call.

<Note>
  The interactive endpoint reference is coming soon. Until then, each area of the API is documented in context below with example requests.
</Note>

## Authentication

| Surface | Credential |
| --- | --- |
| `/api/*` | Bearer token from a login session |
| `/api/mcp` (MCP gateway) | Scoped delegation token |
| `/v2/*` (image registry) | Registry Basic or Bearer credentials |

See [access control](/onboarding/acl/overview) for how permissions are evaluated.
