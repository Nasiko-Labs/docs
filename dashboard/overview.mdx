The dashboard ships inside the Nasiko server. Open your cluster URL — nothing extra to install. It reads the same data the CLI and API do.

## Signing in

Sign in with a username and password at your cluster URL. GitHub, Google, and Microsoft buttons appear only if your organization has enabled them.

<Info>
  **Enterprise.** GitHub OAuth is wired in the open-source server. Microsoft/Google SSO buttons need the OIDC login route, which is `nasiko-ee` only — see [SSO and SCIM](/governance/sso-and-scim).
</Info>

Sessions are stored in a secure cookie. When a session expires, the app returns you to the login screen.

## Navigation (open-source)

The rail, left to right:

| Screen | Path | What it is |
| --- | --- | --- |
| **Overview** | `/` | Fleet health and spend. See [TokenOps dashboard](/tokenops/dashboard) |
| **Orchestrator** | `/orchestrator` | Chat without naming an agent. [Chat](/dashboard/chat) |
| **Agents** | `/agents` | Catalog, Your Agents, Add Agent, Builds. [Agents](/dashboard/agents) |
| **Sessions** | `/chats` | Transcripts, including coding-agent sessions. [Sessions](/dashboard/sessions-and-traces) |
| **Observability** | `/sessions` | Traces, tokens, latency over the same rows |
| **MCP gateway** | `/mcp` | Connectors and toolkits. [MCP](/dashboard/mcp-gateway) |
| **LLM router** | `/llm-router` | Providers and reasoning-level configs. [LLM router](/models/llm-router) |
| **TokenOps** | `/tokenops` | Cost view. [TokenOps](/tokenops/dashboard) |
| **Settings** | `/settings` | General, flow limits, registry, SSO. [Settings](/dashboard/settings) |

Also in the module trees, not all on the rail: **Workflows** and **Executions** ([Workflows](/dashboard/workflows)), **Set up CLI**, **Flows**, **Resources**, **Secrets**.

<Info>
  **Enterprise.** **Departments**, **Teams**, **Users** (full org hierarchy), **Team Access**, **Agent Runtime**, and **Group Mappings** appear in `nasiko-ee` only. Open-source **Users** and access grants still exist without that hierarchy.
</Info>

## Artifact registry

<Info>
  **Enterprise.** The artifact registry is a standalone `nasiko-ee` service. Open-source ships the embedded image registry at `/v2/*` and a client (`nasiko registry connect/search/list`) that can point at an Enterprise registry if you have one.
</Info>
