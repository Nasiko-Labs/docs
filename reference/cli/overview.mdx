`nasiko` discovers coding agents, deploys A2A agents, and talks to your Nasiko cluster. Install: [Install and connect](/install). Task guides stay short and link here for flags.

```bash
nasiko --help
nasiko <command> --help
```

State: `~/.nasiko/config.json` (clusters, tokens) and `~/.nasiko/.env` (local `up`). Every command uses the **active cluster** (`nasiko use`).

Hidden helpers (`__claude-token`, `__coding-agent-token`, `integration`, `agents report`) are for installed hooks. Don't call them yourself.
